# OneDay

**OneDay 是面向桌面和手机浏览器的个人待办、日历与笔记工作空间。** 它将任务、每日时间线、笔记和回顾放在一起，注重个人数据的隐私边界。[English](README.md)

## 功能

- 记录任务，设置状态、优先级、日期、标签和子任务。
- 用时间线安排一天、查看日历并记录实际工作。
- 编写 Markdown 风格笔记，使用统计页面回顾活动。
- 适配桌面和手机浏览器，提供外观主题。
- 导入、导出 JSON 备份。Sites 版 JSON 备份不包含附件原始字节，附件需另行保存。

## 数据与隐私

主线包含面向 Sites 的实现：服务端 API 依赖平台提供的认证身份和 D1/R2 绑定，记录按认证用户隔离，附件使用 R2。认证和隔离依赖可信平台的正确配置，不能只靠这份代码保证。不要将 API 放在允许客户端伪造身份请求头的代理后面。数据可能存储在托管服务商处，代码不提供端到端加密。

独立的本地演示适配器使用浏览器本地存储和示例数据；浏览器清理或损坏可能导致数据丢失。本地演示和 Oil UI 实验均不提供跨设备同步。Sites 后端包含远程存储与冲突处理，但本仓库不提供开箱即用的独立同步服务。请备份重要数据，并在正式使用前验证自己的部署。

## 本地开发

需要 Node.js 22.13 或更新版本及 npm：

```sh
npm ci
npm run dev
```

打开终端显示的本机地址（通常为 `http://127.0.0.1:5173`）。便携开发配置仅在本机模拟登录；生产认证和存储需要兼容的托管环境。运行 `npm run build` 构建。D1 迁移位于 `drizzle/`；部署前需自行配置绑定并应用迁移。不要提交真实凭证、项目 ID 或私人数据。

安装依赖后，可用 Node 测试运行器执行核心及服务端测试：

```sh
node --test tests/core.test.cjs tests/lite/*.test.cjs tests/cloud/*.cjs tests/cloud/*.test.mjs
```

部分浏览器和构建脚本还需要 Python 与浏览器工具，具体参见 `tests/` 和 `tools/`。

## 分支与历史

`main` 保留 OneDay 原版界面；`test/oil-ui` 是从同一快照派生的独立视觉实验，不合并到主线，构建的是使用浏览器本地存储的静态演示。公开历史从本次审查后的快照开始，不包含此前的私有 Site 历史。历史文档可能描述过去的部署，不代表当前部署仍可用；历史截图未纳入公开快照。

## 技术与许可

工作空间使用 JavaScript、HTML、CSS；Sites 版使用 Vinext/Cloudflare Worker 封装以及面向 D1/R2 的 API。关键词：个人待办、任务管理、日程计划、日历、笔记、隐私、响应式网页应用。

项目尚未指定许可证；除适用法律允许的范围外，请勿假定可以复用或再分发。第三方组件仍遵循各自的许可证。

快照中的旧版 WorkBuddy 表标识已替换为通用占位符。独立接入 WorkBuddy 时须映射到自己的表，不要使用他人的标识。
