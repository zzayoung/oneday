## 技能与设计方向

使用 **Oil UI v0.31.0**，来源为 [oil-oil/oil-ui](https://github.com/oil-oil/oil-ui)，固定上游提交 `5b03da0997e0c57650880c521bf5462696d3efe9`。

选定方向为 **「时间索引」**：日期负责定位，完整任务放在可读的宽度中，单日详情承接安排与写作。沿用 OneDay 的图标、编辑器、任务模型和主要动作，不引入运行时 UI 依赖。

主要变化：

- **月历：** 保留完整七列、本周强调、今天标识与日期元数据；减少日期格子的独立阴影和重复边框。桌面增加右侧当日摘要，手机放在月历下方；窄格中的任务线索只作单行省略，完整标题在摘要中阅读。
- **单日工作区：** 桌面保持时间轴与详情并列，并扩大正文区域。手机改为整宽时间轴在上、整宽详情在下；选择任务后定位到详情。Coverflow、时间拖动、四象限、标签、内容与日志仍使用原控制器。
- **记录与控件：** 缩减介绍区和短卡片的多余空白，统一正文、标题与辅助信息层级；增加「时间索引 · Oil UI」纸白与松绿配色，原主题仍可选择。
- **对照：** 保留原版入口，并提供可操作的手机并排对照页。

## 数据与运行方式

这是使用**独立本地样例数据**的 UI 试验，不连接正式站的云端数据库或附件存储，也不提供跨设备同步。

- 数据键：`oneday.oil-lab.v1.local-data`；Oil UI 与原版对照共用这组测试数据。
- 偏好及草稿作用域：Oil UI 为 `oil-lab`，原版对照为 `oil-lab-base`。
- 测试 Site 配置仅为静态 `dist`，没有原项目的 D1/R2 绑定。原迁移文件保留在 `docs/original/oil-lab-db-migrations/` 作为参考，不进入静态站点的运行迁移目录。
- 当日摘要的安排与完成数量来自当前筛选；实际执行时长沿用原有当天去重统计，未用计划时长替代。

## 实现入口与构建

```bash
python3 tools/build_oil_lab.py
```

构建输出：

| 产物 | 用途 |
| --- | --- |
| `dist/index.html` | Oil UI 试验界面 |
| `dist/baseline.html` | OneDay 1.9 原版对照 |
| `dist/compare.html` | 两个可操作的手机视图并排比较 |

视觉样式、摘要渲染和试验控制位于 `src/oil/`；`tools/build_oil_lab.py` 组合现有 Lite 应用并注入试验层。构建检查脚本语法、替换本地数据命名空间，并移除中间 Lite 输出。

`src/lite/timeline.js` 的分支内改动用于适配手机主滚动容器：绘制前保存工作区滚动位置，挂载后恢复；明确选择任务时再通过 `L.revealDaySelection` 定位详情。Oil UI 回调在 `src/oil/oil.js` 中定义；不依赖全局点击推断或新增拖动检测。
