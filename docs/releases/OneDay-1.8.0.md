# OneDay 1.8.0

日期：2026-10-28（Asia/Shanghai）

本次迭代围绕时间线的手机操作和快速记录，沿用原 Site 和已有数据。

## 本版变更

### 时间线内新建

- 时间线弹窗增加 + 入口。
- 在非输入状态下，按 `/` 或 `+` 打开新建窗口；关闭新建后继续原时间线。
- 正文输入、中文输入法组词、组合快捷键和其他弹窗不会误触发新建。
- 顶部 + 默认添加待办；点击时间线空白时刻仍可按该时刻创建。

### Coverflow 和手机拖动

- 卡片随手指/鼠标连续移动，松开平滑归位，可循环切换。
- 切换 Coverflow 不重建右侧正文编辑器。
- 手机可从任务卡任意区域开始拖动；上下边缘继续调节起止时间，时间线空白区域保留滚动。
- 拖动时在卡片上方显示起止时间；触屏跨过时间刻度时尝试轻振反馈。
- 震动是否实际发生取决于手机硬件、浏览器及系统设置。

### 新建窗口

- 打开后立即聚焦正文编辑器，避免其他控件抢走焦点。
- 分类固定为待办、灵感、记录、引用四个选项，移除多余分类滑条。
- 计划时长与分类排列在同一行，适配手机宽度。
- 保留时长 10–480 分钟、10 分钟步进和默认 60 分钟，以及原有草稿、附件和提交中的后续编辑保护。
- 自动弹出手机输入法依赖浏览器允许在用户操作中打开软键盘；当前实现直接在点击/快捷键事件中聚焦。
