# OneDay 1.7 — immediate interaction and a unified record library

The user supplied eight concrete requirements and delegated design decisions for subtasks, themes, naming and reports. Continue implementation and publish to the same owner-private Site without an additional design or deployment approval round.

## Product decisions

1. Timeline drops and resizes update their final position immediately. Cloud persistence is asynchronous; a failed write restores the confirmed state and explains the failure. Initial conflict review uses the already loaded snapshot, instead of rereading all seven tables before every drag. Existing record/version conflict checks remain.
2. Expand the Markdown toolbar with commonly used styles supported by the renderer. Settings expose global line height, block spacing before and after, live preview and reset. Typography applies to editors and rendered Markdown, persists on this device, and does not rewrite document contents.
3. A separate cyclic Coverflow sits above the Day dialog. Horizontal gestures browse it. Cards drag into the timeline; timeline cards drag back to remove their schedule. A top-edge trash target appears during dragging; release soft-deletes, with immediate feedback and undo. The previous parking strip is removed. Pointer/touch/keyboard alternatives retain access to the same actions.
4. Double-clicking a parent expands its children. Unscheduled children can inherit a display range from their parent, clearly marked; moving one creates its own schedule. Children can be added, selected and edited. Parent relationships and time-log semantics remain intact.
5. Day detail has two centered tabs, task content and task logs, with horizontal swipe outside interactive editing controls. The content editor fills available height. Priority becomes a draggable four-quadrant control and tags remain above the editor. A draggable status rail replaces the header's start/check buttons. Status transitions continue to maintain time logs.
6. The shared creation sheet creates one logical **记录**, default category **待办**, with a draggable category rail, one Markdown editor and an **添加** button. Pending records retain duration and contextual timeline timing. The **记录** library includes all new captures, plus existing tasks and notes. Reuse the existing task table for actionable records and notes table for other categories; avoid duplicate records or a destructive migration. Existing work logs remain related records.
7. Add four coherent themes while retaining old theme preference compatibility. New default is mist-blue only when the user has no saved preference.
8. Add **统计** alongside calendar/board: week, month, quarter, half-year, year and custom periods; completed items, recorded activity, actual time, daily trend and categories; editable, copyable/exportable Chinese report drafts. Actual time unions overlap; completion uses completion time, never planned deadlines. Planned work is distinguished from actual activity.
