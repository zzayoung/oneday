# OneDay Lite 1.4 · Sites 设计基线

## 目标与授权

接续用户明确指定的 OneDay ZZtodo 和 Lite 1.3 Rich Workspace，完成已授权的后端适配、可靠性修复及私人 GPT Sites 发布。原始依据在 `docs/original/SITES-HANDOFF.md`，其中明确要求继续执行，不重复设计确认。保持现有个人任务与笔记产品，不引入另一套管理系统。

## 保留

保留底部任务 / ＋ / 笔记、任务日历 / 看板、Day Sheet、主子任务轴、未定时区、默认单轨与显式并行、五主题和实时 Markdown。原 WorkBuddy 构建继续保留。保留七类记录 tasks/logs/notes/tags/links/sets/cal 的 ID、关系、未知字段、原计划墙钟语义和实际执行 UTC 时间。Sites 首次数据库为空；不写入体验数据，不自动修改或同步 WorkBuddy。

## 实现

- 原前端继续由 Python 拼装；新增 `src/lite/cloud.js` 与 Sites 构建目标。Vinext 根 Route Handler 返回完整原页面，避免 iframe 和重做 UI。
- 私人 Site 使用平台 ChatGPT 身份。服务端所有记录和附件操作均按可信身份 header 限定归属；没有身份返回 401。浏览器草稿按 Site 用户隔离。
- D1 存七类 JSON 业务记录与版本，R2 保存真实附件字节。版本 CAS 阻止并发静默覆盖；稳定请求 ID 防止重复新增。状态切换及对应时间日志在同一事务完成。
- 服务端分页；直接读取单条记录代替每次修改前扫描整张表；可见时检查版本变化再刷新；保存成功以服务端返回为准。
- 云备份包含全七类业务记录与附件清单。导入先展示数量、冲突与附件迁移边界，合并新增、跳过相同记录、拒绝覆盖不同内容的同 ID；可重复恢复。
- 编辑器补齐 Markdown 表格往返、上传期间输入保护、中文输入及光标稳定。Day / Note / Creation Sheet 使用已有本机草稿机制，保存失败保留，刷新可恢复。

## 边界

此版本不把本机缓存称为云备份，不实现后台离线自动提交，不承诺 WorkBuddy 旧附件已复制到 Sites。导入保留旧链接；JSON 备份包含附件清单，不包含文件字节。附加文件限制 20 MiB，拒绝 HTML/SVG/可执行脚本。文件读写同样需要当前用户身份。

## 验收

回归原核心与存储测试；新增权限隔离、真实 SQLite/D1 查询、CAS 竞争、重复请求、状态日志事务、分页、文件往返、导入拒绝覆盖测试。浏览器 QA 使用当前支持的 Sites 预览及 Browser；不为验收绕过登录或伪造真实用户身份。部署须由原生工具返回成功与 URL，实际无法执行的真机/登录验收明确报告。
